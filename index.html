FIELD NOTE 012

停電点検は「停電OK」だけで切らない

停電点検安全確認管理会社

管理会社が間に入る現場では、その指示を遵守する。設置者がOKを出しても、弱電やサーバーの処理中かもしれない。

停電前に、他業者・エレベーター・駐車場・関係者への連絡を確認する。
FIELD NOTE 011

リレー試験で小さい端子を掴むクリップ

保護継電器試験工具

OCR試験器の配線は重く、小さい端子ではクリップが外れやすい。

自分は1mの延長クリップで十分。配線本体を床置きにでき、小さいネジにも取り付けやすい。

FIELD NOTE 010

OVGRの150%試験は印加電圧に注意

OVGRZPD保護継電器試験

整定値10%でT-Eの動作電圧が約381Vなら、150%試験は約571V（381V×1.5）。

確認：50/60Hz・試験器のレンジ/ツマミ・ZPDのT-E試験電圧。
T-Eの試験電圧はメーカー・機種で異なる。特に三菱製は要確認。

FIELD NOTE 002

耐圧前に充電電流を把握する

耐圧試験充電電流

耐圧前に、流れるはずの充電電流を把握しておく。

想定した電流が流れないなら、そのまま昇圧せず接地・接続・試験回路を確認。
FIELD NOTE 001

単体耐圧はクランプで充電電流を見る

耐圧試験PASUGSVCB

PAS・UGS・VCBの単体耐圧は充電電流が小さい。

試験器で見えにくい時は、微小電流を測れるクランプで補助確認する。
