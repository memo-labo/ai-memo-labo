OCR
過電流継電器

過負荷や短絡による過電流をCTで検出し、必要な時間特性で遮断器を動作させる保護継電器。旧memo-laboに分散していたOCR関連情報を、原理→整定→保護協調→試験の順にまとめ直した。

1. OCRは何をしているのか

OCR（Over Current Relay、機器番号51）は、CTの二次電流から過電流を検出する。通常の負荷変動では動作せず、過負荷が継続した場合や短絡電流が流れた場合に接点を動作させ、VCBを開放する。

OCRを理解するときは、限時要素と瞬時要素を分けると整理しやすい。限時は主に過負荷、瞬時は主に短絡事故を対象とする。

2. 限時要素

限時要素は、電流が大きいほど短い時間で動作する特性を利用して設備を保護する。代表的な特性は超反限時（EI）、強反限時（VI）、反限時（NI）。機器の熱特性や上位・下位保護装置との協調を見ながら選ぶ。

特性考え方
超反限時 EI発熱特性に合わせやすく、MCCBやヒューズとも協調を取りやすい
強反限時 VI配電線・変圧器などの過負荷保護に使われる
反限時 NI送配電線の保護などに使われる

限時タップの考え方

通常負荷では動作しない値にしつつ、設備を保護できる範囲に整定する。旧記事で使っていた目安式は次のとおり。

I(tap) = { P / (√3 × 6.6kV) × (5 / CT一次電流) } × 1.5

例として契約電力200kW、CT比30/5Aなら計算値は約4.4Aとなり、その上位の整定値として5Aを選ぶ考え方になる。

重要：実際の整定は設備容量だけで決めず、電力会社側の保護特性、変圧器、下位遮断器、突入電流などを含めて保護協調を確認する。

3. 瞬時要素

瞬時要素（50）は短絡などの大電流を高速に検出する。一方、変圧器投入時の励磁突入電流で不要動作しない整定が必要になる。

瞬時要素 ≒ P(kVA) × 4.35 / CT一次電流
※旧記事で「定格一次電流の10倍」を目安にした簡略式

800kVA、CT 100/5Aなら計算値は34.8A。整定段階に40Aがあれば40Aを選択する例になる。

4. 保護協調

需要家構内の事故では、構内OCRとVCBが電力会社側より先に事故区間を切り離す必要がある。需要家側の動作が遅すぎると上位遮断器まで動作し、事故範囲が広がる可能性がある。

OCR単体の動作時間だけでなく、VCBの開極時間も含めて考える。50Hzで3サイクル定格なら開極時間の目安は0.06秒。

5. 電流引き外しと電圧引き外し

電流引き外しは事故時のCT二次電流を利用してトリップさせる方式。OCR内部のトリップ用接点が動作してVCB側へ電流を振り替える。

電圧引き外しは制御電源を利用し、OCRのa接点が閉じることでVCBトリップコイルへ電圧を印加する。CT電流回路とトリップ回路を分けて考えられる。

6. 誘導形OCR MOC-2

誘導形は円盤の回転を利用して動作する旧来型OCR。MOC-2では限時3・4・5・6・8A、瞬時20・30・40・60・80Aなどの整定段階を持つ機種がある。

ダイヤル1の参考動作時間は、200%で1.0秒、300%で0.4秒、500%で0.2秒、700%で0.14秒。試験では想定時間を事前に把握し、接点を検出できず電流を流し続けないよう注意する。

7. 試験のポイント

限時要素は整定電流に対する倍率を変え、規定された時間特性に入るか確認する。静止形OCRでは200%、300%、500%、700%などで特性を確認するケースがある。

瞬時要素は高電流が必要になるため、試験器や電源容量に注意する。旧記事では整定値を一時的に下げて200%を印加する試験例も扱っている。

戻し忘れ注意：試験のためタップ・瞬時値・ダイヤル等を変更した場合、試験終了後に必ず元の整定値へ復帰し、記録と照合する。

8. 現場で見る順番

OCRで迷ったときは、①CT比 → ②限時タップ → ③特性種別 → ④ダイヤル → ⑤瞬時値 → ⑥引き外し方式 → ⑦VCBとの連動 → ⑧上位・下位との保護協調、の順で追うと整理しやすい。
